# Quick Mart - Product Overview

Quick Mart is a grocery delivery iOS app built with SwiftUI. The app provides a comprehensive shopping experience with the following key features:

## Core Features
- **Home Dashboard**: Promotional banners, quick actions, category browsing, and popular products
- **Product Catalog**: Browse products by category with search functionality
- **Shopping Cart**: Add/remove items, quantity management, and checkout flow
- **Order Management**: Track active orders and view order history
- **User Profile**: Account management, settings, and preferences

## Target Platform
- iOS mobile application
- Built for iPhone with SwiftUI framework
- Supports modern iOS design patterns and user interactions

## Key User Flows
1. Browse products by category or search
2. Add items to cart with quantity selection
3. Checkout with address and payment selection
4. Track order status in real-time
5. View order history and reorder items

The app follows a tab-based navigation structure with five main sections: Home, Shop, Cart, Orders, and Profile.
